  <action>
    **create-project.ts:**

    Create `packages/create-aws-project-mcp/src/tools/create-project.ts` that exports `registerCreateProjectTool(server: McpServer)`:

    - Import `McpServer` from `@modelcontextprotocol/sdk/server/mcp.js` and `z` from `zod`
    - Import `runCreateProjectNonInteractive` from `create-aws-project`
    - Import `withCliContext` from `../utils/cli-context.js`
    - Use `server.registerTool('create_project', { ... }, handler)` (NOT the deprecated `server.tool()`)
    - Input schema (Zod):
      ```
      name: z.string().describe('Project name (must be valid npm package name)')
      outputDir: z.string().optional().describe('Output directory (defaults to cwd)')
      platforms: z.array(z.enum(['web', 'mobile', 'api'])).optional()
      auth: z.enum(['none', 'cognito', 'auth0']).optional()
      features: z.array(z.enum(['github-actions', 'vscode-config'])).optional()
      region: z.string().optional().describe('AWS region (default: us-east-1)')
      brandColor: z.enum(['blue', 'purple', 'teal', 'green', 'orange']).optional()
      ```
    - Handler receives `(args, extra)` where extra is `RequestHandlerExtra`
    - Emit progress notification at start (progress: 0, total: 2) if `extra._meta?.progressToken !== undefined`
    - Wrap the call in `withCliContext`: `const { result } = await withCliContext(() => runCreateProjectNonInteractive(args))`
    - Emit progress notification at end (progress: 2, total: 2)
    - Return `{ content: [{ type: 'text', text: JSON.stringify({ projectDir: result.projectDir }) }] }`
    - On error: return `{ isError: true, content: [{ type: 'text', text: error.message }] }`

    **get-project-status.ts:**

    Create `packages/create-aws-project-mcp/src/tools/get-project-status.ts` that exports `registerGetProjectStatusTool(server: McpServer)`:

    - Input schema: `projectDir: z.string().describe('Absolute path to the project directory')`
    - Handler reads `path.join(projectDir, '.aws-starter-config.json')` using `fs.readFile`
    - Parse the JSON as `ProjectConfigMinimal` shape (inline type or import)
    - Compute `nextSteps` array:
      - If `accounts` is empty or missing entries: "Run setup_aws_envs to configure AWS accounts"
      - If `deploymentCredentials` is empty or missing entries: "Run setup_aws_envs to create deployment credentials"
      - If both present: "Project is fully configured. Ready to deploy."
    - Return structured JSON: `{ projectName, configVersion, awsRegion, platforms, accounts, deploymentUsers, deploymentCredentials, nextSteps }`
    - On file not found / parse error: return `{ isError: true, content: [{ type: 'text', text: 'Failed to read project config: ...' }] }`
    - No progress notifications (fast read-only operation)

    **server.ts:**

    Update `packages/create-aws-project-mcp/src/server.ts`:
    - Import `registerCreateProjectTool` from `./tools/create-project.js`
    - Import `registerGetProjectStatusTool` from `./tools/get-project-status.js`
    - Call both after creating the McpServer instance, before connecting transport
    - Remove the `// Tools will be registered here in Phase 28` comment

    Run `cd packages/create-aws-project-mcp && npm run build` to verify compilation.
