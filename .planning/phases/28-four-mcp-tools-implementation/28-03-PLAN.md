    **setup-aws-envs.ts:**

    Create `packages/create-aws-project-mcp/src/tools/setup-aws-envs.ts` that exports `registerSetupAwsEnvsTool(server: McpServer)`:

    - Input schema (Zod):
      ```
      projectDir: z.string().describe('Absolute path to the project directory')
      email: z.string().describe('Root email for deriving per-environment account emails')
      ```
    - Handler flow:
      1. Check credentials FIRST: call `requireEnvVars(['AWS_ACCESS_KEY_ID', 'AWS_SECRET_ACCESS_KEY'])` from `./errors.js`
      2. Emit progress (0/3) if progressToken present
      3. `process.chdir(projectDir)` — required because `detectProjectContext()` uses `findUp` from `process.cwd()`. This is safe because MCP server handles one request at a time over stdio.
      4. Wrap call in `withCliContext`: `await withCliContext(() => runSetupAwsEnvsNonInteractive({ email: args.email }))`
      5. Emit progress (2/3) after setup completes
      6. Emit progress (3/3) done
      7. Return JSON with success status
    - Error handling:
      - `MissingCredentialsError`: return `{ isError: true, content: [{ type: 'text', text: error.message }] }` (message already includes .mcp.json snippet)
      - Generic errors: return `{ isError: true, content: [{ type: 'text', text: error.message }] }`
    - Save and restore `process.cwd()` before/after `chdir` in a try/finally block

    **initialize-github.ts:**

    Create `packages/create-aws-project-mcp/src/tools/initialize-github.ts` that exports `registerInitializeGitHubTool(server: McpServer)`:

    - Input schema (Zod):
      ```
      projectDir: z.string().describe('Absolute path to the project directory')
      repoUrl: z.string().describe('GitHub repo (owner/repo, HTTPS URL, or SSH URL)')
      environments: z.array(z.enum(['dev', 'stage', 'prod'])).optional().describe('Environments to configure (defaults to all with credentials)')
      ```
    - Handler flow:
      1. Check credentials FIRST: call `requireEnvVars(['GITHUB_TOKEN'])` from `./errors.js`
      2. `process.chdir(projectDir)` (same CWD reason as setup_aws_envs)
      3. Wrap call in `withCliContext`: `const { result } = await withCliContext(() => runInitializeGitHubNonInteractive({ repoUrl: args.repoUrl, environments: args.environments }))`
      4. Return JSON with result (per-environment status from the function's return value)
    - No progress notifications (initialize_github is not listed as long-running in SAFE-04)
    - Error handling: same pattern as setup_aws_envs — MissingCredentialsError and generic errors both return `isError: true`
    - Save and restore `process.cwd()` in try/finally

    Update `packages/create-aws-project-mcp/src/server.ts` to also import and call:
