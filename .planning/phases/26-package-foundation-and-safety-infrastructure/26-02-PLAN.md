Create `packages/create-aws-project-mcp/src/utils/cli-context.ts` with:

1. Export `CliContextResult<T>` interface:
   - `result: T` -- the return value from the wrapped function
   - `capturedOutput: string` -- all stdout writes concatenated

2. Export `async function withCliContext<T>(fn: () => Promise<T>): Promise<CliContextResult<T>>`

Implementation requirements:
- Save `process.stdout.write` binding BEFORE overriding
- Override `process.stdout.write` to capture all chunks into a `Buffer[]` array. Handle both string and Uint8Array chunks. If a callback is provided, call it. Return `true`.
- Save `process.exit` binding BEFORE overriding
- Override `process.exit` to set a local `interceptedExitCode` variable and throw `new Error("process.exit(N) intercepted")`
- In `try` block: call `await fn()`, return `{ result, capturedOutput: Buffer.concat(chunks).toString('utf8') }`
- In `catch` block: if `interceptedExitCode !== undefined`, throw `new Error("Command failed with exit code N")`. Otherwise re-throw.
- **CRITICAL `finally` block**: Restore BOTH `process.stdout.write` and `process.exit` to saved originals. This MUST run unconditionally -- if either is leaked, the MCP server silently dies.

Type casting notes: Use `(process.stdout.write as unknown) = ...` and `(process.exit as unknown) = ...` to satisfy TypeScript's `never` return type on `process.exit`.
